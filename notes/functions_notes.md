### 💡 functions || Les piliers d'une fonction en Python

* **`def`** : Mot-clé indispensable pour **déclarer** (définir) une fonction.
* **Paramètres** : Les variables placées entre les parenthèses `()` dont la fonction a besoin pour accomplir son travail.
* **`return`** : Indique la valeur finale que la fonction **renvoie** à la fin de son exécution. 
  * ⚠️ *Attention :* Dès que Python rencontre un `return`, il quitte immédiatement la fonction et ignore le code situé en dessous.
